Lightweight Google Translate language switcher with custom styles, size controls, colors, fonts and keyword exclusion.

== Description ==
Add `[language_switcher_ms]` anywhere. Configure languages, colors, sizes and "do not translate" keywords under Settings > Language Switcher MS.

== External services ==
Loads translate.google.com/translate_a/element.js (Google Translate) and flag images from flagcdn.com on the front end.
